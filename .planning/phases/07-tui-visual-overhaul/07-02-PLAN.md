## InlineToolCall Specification

**File:** `tui/widgets/inline_tool_call.py`

**Class:** `InlineToolCall(Static)`

**States:**
| State | Collapsed Rendering | Expanded Rendering |
|-------|--------------------|--------------------|
| Pending | `○ search_web` (blue, italic) | Args (JSON Syntax) + "Waiting for result..." |
| Success | `✓ read_file` (green) | Args (JSON Syntax) + Result preview (first 2000 chars) |
| Error | `✗ write_file` (red) | Args (JSON Syntax) + Error text |

**Reactive:**
- `_collapsed = reactive(True)` — toggled by `on_click`

**Methods:**
- `__init__(tool_call_id, name, args)` — store id, name, args; render content
- `set_result(result)` — store result, re-render
- `set_error(error)` — store error, re-render
- `on_click()` — toggle `_collapsed`
- `watch__collapsed()` — re-render on collapse state change
- `_render_content()` — build Rich Text/Group for current state
- `tool_call_id` (property) — return `self._tool_call_id`

**Rendering details:**
- Collapsed pending: `○ tool_name` with `$secondary` color, italic
- Collapsed success: `✓ tool_name` with `$success` color
- Collapsed error: `✗ tool_name` with `$error` color
- Expanded: Show args as Syntax(json, "monokai") then result text
- Use `rich.text.Text` and `rich.syntax.Syntax` for content
- Use `self.update(rich_renderable)` pattern (same as current ToolCallCard)

**CSS classes** (from theme.tcss, already created in Plan 07-01):
- `InlineToolCall` — margin 0 1 0 2, padding 0 1, color $secondary, text-style italic
- `InlineToolCall.--expanded` — color $text, background $surface, border solid $panel 50%

    Create `tui/widgets/inline_tool_call.py` with the InlineToolCall class.

    Per RESEARCH.md code example (lines 434-522) and CONTEXT.md decisions D-07/D-08/D-09:

    ```python
    from __future__ import annotations

    import json

    from rich.syntax import Syntax
    from rich.text import Text
    from textual.reactive import reactive
    from textual.widgets import Static


    class InlineToolCall(Static):
        """Compact inline tool call within message stream. Click to expand/collapse.
        
        Renders as a one-line entry showing tool name + status icon when collapsed.
        Expands to show JSON-syntax-highlighted args and result/error on click.
        Replaces ToolCallCard per D-07, D-08, D-09.
        """

        _collapsed = reactive(True)

        def __init__(self, tool_call_id: str, name: str, args: dict) -> None:
            self._tool_call_id = tool_call_id
            self._name = name
            self._args = args
            self._result: str | None = None
            self._error: str | None = None
            super().__init__()
            self._render_content()

        @property
        def tool_call_id(self) -> str:
            return self._tool_call_id

        def set_result(self, result: str) -> None:
            self._result = result
            self._error = None
            self._render_content()

        def set_error(self, error: str) -> None:
            self._error = error
            self._result = None
            self._render_content()

        def on_click(self) -> None:
            self._collapsed = not self._collapsed

        def watch__collapsed(self) -> None:
            self._render_content()

        def _render_content(self) -> None:
            if self._collapsed:
                # One-line: "○ read_file" or "✓ read_file" or "✗ read_file"
                if self._result:
                    icon = "[green]✓[/green]"
                elif self._error:
                    icon = "[red]✗[/red]"
                else:
                    icon = "[blue]○[/blue]"
                self.update(f"  {icon} [italic]{self._name}[/italic]")
                self.remove_class("--expanded")
            else:
                # Expanded: show args + result/error
                self.add_class("--expanded")
                args_syntax = Syntax(
                    json.dumps(self._args, indent=2),
                    "json",
                    theme="monokai",
                    word_wrap=True,
                )

                if self._error:
                    body = Text(self._error, style="red")
                elif self._result:
                    result_preview = (
                        (self._result[:2000] + "...")
                        if len(self._result) > 2000
                        else self._result
                    )
                    body = Text.assemble(
                        ("Arguments:\n", "bold"),
                        args_syntax,
                        ("\n\nResult:\n", "bold"),
                        (result_preview, "green"),
                    )
                else:
                    body = Text("Waiting for result...", style="dim italic")

                self.update(body)
    ```

    Key design decisions:
    - Uses `Rich` markup strings for collapsed state (fast, lightweight)
    - Uses `Syntax` for expanded args display (same as ToolCallCard)
    - Uses `add_class("--expanded")` / `remove_class("--expanded")` for CSS transitions (theme.tcss already has the `.--expanded` rule from Plan 07-01)
    - No Panel wrapper — tool calls render as flat content within the message flow, not as bordered cards
    - `tool_call_id` property preserved for downstream correlation
