<objective>
Wire the persist filter into serialization: `Session.to_events()` skips `persist=False` messages, and `Session.mark_saved()` counts persisted messages only — closing the D-13 JSONL leak while fixing the index-drift bug (ACT-05).

Purpose: This is the highest-risk change in the milestone. The current `mark_saved()`/`unpersisted_events()` pairing assumes `to_events()` is a 1:1 projection of `_context._messages`; once filtering exists, the `_last_saved_count` index must count persisted messages or repeated saves lose/duplicate events. Round-trip tests prove the store contract end-to-end.
Output: Persist-safe `to_events()` + `mark_saved()` in `session/models.py` + round-trip tests appended to `tests/test_persist.py`.
</objective>

def to_events(self) -> list[dict]:            # L77-86
    events = []
    for msg in self._context._messages:
        d = {"role": msg.role, "content": msg.content, "token_count": msg.token_count}
        if msg.tool_calls:
            d["tool_calls"] = [asdict(tc) for tc in msg.tool_calls]
        if msg.tool_call_id:
            d["tool_call_id"] = msg.tool_call_id
        events.append(d)
    return events

def unpersisted_events(self) -> list[dict]:   # L100-102
    all_events = self.to_events()
    return all_events[self._last_saved_count:]

def mark_saved(self) -> None:                  # L104-106
    if self._context is not None:
        self._last_saved_count = len(self._context._messages)
