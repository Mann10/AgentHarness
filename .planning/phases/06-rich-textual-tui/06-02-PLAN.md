### 4. Enhance InputBar

**File:** `tui/widgets/input_bar.py` (modify)

**Current:** Extends `Input`, fixed placeholder.

**New features:**
- **Command history:** Store previous submissions in a list. Up/down arrows navigate history.
- **Command autocomplete:** When input starts with `/`, show a popup with matching commands:
  - `/sessions`, `/new`, `/resume`, `/title`, `/help`, `/exit`
  - Tab to complete, Enter to select
- **Character count:** Show `N chars` right-aligned in the bar when content > 0
- **Placeholder rotation:** Default "Type a prompt...", changes to "Type / for commands" when user types `/`

**New event handler:**

**Update existing handlers** to also drive sidebar and timeline:
- `_on_turn_started` → `sidebar.update_job_status(id, PROCESSING)`
- `_on_tool_call` → `timeline.add_chip(id, name)`, `sidebar.update_job_status(id, PROCESSING)`
- `_on_tool_result` → `timeline.update_chip(id, "done")`
- `_on_response_complete` → `timeline.clear()`, `sidebar.update_job_status(id, COMPLETE)`
- `_on_error` → `timeline.update_chip(id, "error")`, `sidebar.update_job_status(id, FAILED)`
- `_on_cancelled` → `timeline.clear()`
