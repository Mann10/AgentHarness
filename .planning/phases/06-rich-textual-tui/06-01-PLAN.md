### 2. Build MessageCard

**File:** `tui/widgets/message_card.py`

**Widget:** `Static` subclass with Rich rendering.

**Variants:**
- **User:** prefix `> ` in dim style `rgb(86,95,137)`, single line, truncated at 200 chars
- **Assistant:** full text rendered via `rich.markdown.Markdown` with `code_theme="monokai"`. Left side border via Rich markup.
- **Error:** `rich.panel.Panel` with red border, error text
- **Notice:** italic text in dim style

**API:**
```python
@staticmethod
def user(content: str) -> MessageCard

@staticmethod
def assistant(content: str) -> MessageCard

@staticmethod
def error(text: str) -> MessageCard

@staticmethod
def notice(text: str) -> MessageCard
```

### 3. Build ToolCallCard

**File:** `tui/widgets/tool_call_card.py`

**Widget:** `Static` subclass. Collapsible Rich `Panel`.

**States:** pending (blue, spinner), success (green, ✓), error (red, ✗)

**Collapsed:** single line showing `▶ tool_name` or `▼ tool_name ✓`
**Expanded:** args rendered as syntax-highlighted JSON + result preview

**Interaction:** Click toggles collapse/expand. `tool_call_id` stored as widget attribute for correlation.

**API:**
```python
def __init__(self, tool_call_id: str, name: str, args: dict):
    # starts in collapsed pending state

def set_result(self, result: str):  # transitions from pending → success

def set_error(self, error: str):  # transitions from pending → error
```

### 4. Build ConversationView

**File:** `tui/widgets/conversation_view.py`

**Widget:** `VerticalScroll` container.

**API:**
```python
def add_user_message(self, content: str)
def add_assistant_message(self, content: str)
def add_tool_call(self, tool_call_id: str, name: str, args: dict)
def update_tool_result(self, tool_call_id: str, content: str)
def add_error(self, error: str)
def add_notice(self, text: str)
def clear(self)
```

**Behavior:** Each `add_*` method creates the appropriate child widget and mounts it. `update_tool_result` iterates children to find matching `tool_call_id` and calls `set_result` on it. Auto-scrolls to bottom after each add.
