Key facts: `asyncio.CancelledError` is a BaseException in Python 3.12 — `except Exception` never sees it. After a mid-gather cancel, `context._messages` contains the assistant tool_calls message with NO following tool messages → next turn's `to_llm_messages()` has `tool_calls` without matching `tool` results → provider rejects the sequence.
