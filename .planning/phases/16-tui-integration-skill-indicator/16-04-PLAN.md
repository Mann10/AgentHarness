<objective>
Close CR-01 (blocker) and WR-05 from 16-VERIFICATION.md: make the streaming assistant message stream-proof against mid-stream `/skill` notices, and scope the `skill_loaded` chip update to the active session. Then run the missing human E2E scenario — `/skill <name>` **during** a streaming response — as a blocking checkpoint.

Purpose: SC-4 ("the indicator never pollutes the assistant message stream") is currently violated. `addSkillNotice` inserts a notice after the streaming assistant message; the next `token` event sees a non-assistant last message and spawns a SECOND assistant box, permanently stranding the original with `isStreaming: true` (split turn, stuck ▸ spinner, unrecoverable). The `response_complete` handler has the identical last-message-only flaw. This plan applies the reviewer-suggested fix (backwards scan for the last streaming assistant) at BOTH the handler and store level so the fix is actually effective, plus the WR-05 session-correlation guard. The human E2E re-check is required by the verification report before the phase gate can pass.
</objective>

```typescript
case "token": {
  const p = payload as { session_id: string; chunk: string; request_id: string }
  const state = useAgentStore.getState()
  const lastMsg = state.conversation[state.conversation.length - 1]
  if (!lastMsg || lastMsg.role !== "assistant" || !lastMsg.isStreaming) {
    store.startAssistantMessage()
  }
  store.appendToken(p.chunk)
  break
}
case "response_complete": {
  const p = payload as { session_id: string; content: string; iterations: number; tool_calls_made: number; forced: boolean }
  const state = useAgentStore.getState()
  const lastMsg = state.conversation[state.conversation.length - 1]
  if (lastMsg && lastMsg.role === "assistant" && lastMsg.isStreaming) {
    store.completeAssistantMessage(p.content)
  } else {
    store.addAssistantMessage(p.content)
  }
  store.setStatus("idle")
  store.setBusy(false)
  break
}
case "skill_loaded": {
  const p = payload as { skill: string }
  store.addLoadedSkill(p.skill)
  break
}
```

    ```ts
    // Returns the index of the LAST message with role "assistant" AND isStreaming, or -1.
    function lastStreamingIdx(msgs: Message[]): number {
      for (let i = msgs.length - 1; i >= 0; i--) {
        if (msgs[i].role === "assistant" && msgs[i].isStreaming) return i
      }
      return -1
    }
    ```
