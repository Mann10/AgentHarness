<implementation_spec>
## MessageCard Changes

Per D-04:
- Assistant messages get a subtle dark background via the `--assistant-bg` CSS class
- User messages remain transparent (no background)
- No labels ("You" / "Assistant") are added
- No alignment difference — all messages left-aligned
- Error and notice messages keep their existing styling

**CSS class application:**
The CSS class `--assistant-bg` is already defined in `tui/theme.tcss` (created in Plan 08-01):
```css
MessageCard.--assistant-bg {
    background: $surface;
}
```

The widget code needs to apply this class to the `assistant()` factory method's return value. The method currently returns `MessageCard(Markdown(...))`. After the change, it also adds the CSS class.

Current `assistant()` method:
```python
@staticmethod
def assistant(content: str) -> MessageCard:
    return MessageCard(Markdown(content, code_theme="monokai"))
```

After change:
```python
@staticmethod
def assistant(content: str) -> MessageCard:
    card = MessageCard(Markdown(content, code_theme="monokai"))
    card.add_class("--assistant-bg")
    return card
```

No other methods need changes — `user()`, `error()`, and `notice()` remain unchanged.
</implementation_spec>
