## Stats Tracking Flow

### On TurnStarted (before agent processes prompt):
1. Record `self._turn_start_time = event.timestamp`
2. Update StatsPanel with session name (from runtime.active_session.title or "Untitled")
3. Update StatsPanel with model name (from self._model_name)

### On ResponseComplete (after agent returns response):
1. Compute response time: `(event.timestamp - self._turn_start_time).total_seconds()` formatted as `"X.Xs"`
2. Get token count from `self._runtime.active_session.context.total_tokens`
3. Update StatsPanel with token count and response time
4. Reset tool call count

### Session name and model name:
- Session name: `self._runtime.active_session.title if self._runtime.active_session else "No session"`
- Model name: set at construction, displayed in StatsPanel
