  <how-to-verify>
  Terminal A — TUI streaming (requires an LLM that responds with text):
  1. From `tui-ink/`: `npm run build` then `node dist/index.js`
  2. Send a plain prompt (e.g. "Write a short poem about the ocean").
     EXPECTED: tokens appear live chunk-by-chunk in the assistant message with the blinking green cursor `▸ ... ▊`; the view stays pinned to the newest content even after several exchanges (auto-scroll, D-06).
  3. After completion: EXPECTED the message keeps its full final content, cursor gone (D-07 finalization).
  4. Send a long prompt (e.g. "Write a 500-word essay about terminal interfaces") and press Ctrl+C mid-stream.
     EXPECTED: partial text REMAINS visible followed by the dim-yellow italic ` (truncated)` label; a "Cancelled" notice appears; no dead blinking cursor remains (D-04).
  5. Send a prompt that triggers a tool call (e.g. "What's the weather in NYC?" if built-in weather tool exists).
     EXPECTED: tool call indicator appears; NO streaming cursor during the tool turn; final text streams after the tool result (D-02 tool turns non-streaming).

  Terminal B — REPL batch behavior (D-08):
  6. From project root: `python main.py`, then send the same plain prompt.
     EXPECTED: no token-level output while waiting; the complete final text prints once, on completion.

  Failure record: for any step that does not match EXPECTED, record the exact symptom (terminal output, error text) — do NOT attempt code fixes in this plan.
  </how-to-verify>
